# Pet shop de banho e tosa

<!-- Stacks do projeto -->

É um sistema de controle de um pet shop de banho e tosa. O tutor leva um ou mais
animais e pode solicitar um ou mais serviços (banho, tosa, hidratação ou pacote
completo). Cada animal tem um porte (pequeno, médio ou grande), que define o
preço do serviço. O atendente registra o tutor e seus animais, indicando o serviço
desejado para cada um. O sistema calcula o valor total ao final.
